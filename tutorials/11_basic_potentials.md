## Introduction: The Progressive Approach

In this tutorial, we will run the **same physical system** (argon atoms) with increasingly complex potentials:

1. **LJ only** → Can predict: fluid structure, density
2. **LJ + Bonds** → Can predict: vibrational frequencies, molecular identity
3. **LJ + Bonds + Angles** → Can predict: molecular shape, phase behavior
4. **LJ + Bonds + Angles + Dihedrals** → Can predict: conformational preferences, barriers

Each step reveals what new physics the added complexity captures.

## Part 1: Pure Lennard-Jones Fluid

### 1.1 The System: Liquid Argon

We'll simulate 500 argon atoms in a periodic box at 300 K and 1 atm.

**What LJ Can Predict:**
- ✅ Liquid-vapor phase diagram
- ✅ Radial distribution function (local structure)
- ✅ Diffusion coefficient
- ✅ Pressure and density

**What LJ Cannot Predict:**
- ❌ Anything requiring bonds (molecules don't exist)
- ❌ Directional interactions (all atoms identical)

### 1.2 LAMMPS Input File

Create a file called `argon_lj.in`:

```lammps
# Liquid Argon Simulation - Pure Lennard-Jones
# Tutorial 11 - Part 1

# ========================================
# 1. Initialization
# ========================================
units           real                    # Angstrom, kcal/mol, fs
atom_style      atomic                  # No bonds, just atoms
boundary        p p p                   # Periodic in all directions

# ========================================
# 2. Create Atoms
# ========================================
lattice         fcc 5.26                # FCC lattice, density ~ liquid Ar
region          box block 0 4 0 4 0 4   # 4x4x4 unit cells
create_box      1 box                   # 1 atom type
create_atoms    1 box                   # Fill box with type 1

mass            1 39.948                # Argon atomic mass (g/mol)

# ========================================
# 3. Lennard-Jones Potential
# ========================================
pair_style      lj/cut 10.0             # LJ with 10 Angstrom cutoff
pair_coeff      1 1 0.238 3.405         # epsilon=0.238 kcal/mol, sigma=3.405 A

# ========================================
# 4. Settings
# ========================================
neighbor        2.0 bin                 # Neighbor list skin distance
neigh_modify    every 1 delay 0 check yes

# ========================================
# 5. Equilibration (NVT)
# ========================================
velocity        all create 300.0 12345  # Initialize velocities at 300K
fix             1 all nvt temp 300.0 300.0 100.0  # Nose-Hoover thermostat

timestep        2.0                     # 2 fs timestep
thermo          1000                    # Print every 1000 steps
thermo_style    custom step temp pe ke etotal press density

run             50000                   # 100 ps equilibration

# ========================================
# 6. Production (NVT)
# ========================================
reset_timestep  0
dump            1 all custom 1000 argon_lj.lammpstrj id type x y z
dump_modify     1 sort id

# Compute radial distribution function
compute         rdf all rdf 100 1 1     # 100 bins, type 1 with type 1
fix             2 all ave/time 100 10 1000 c_rdf[*] file argon_rdf.dat mode vector

run             100000                  # 200 ps production

write_data      argon_final.data        # Save final configuration
```

### 1.3 Running the Simulation

## Part 2: Diatomic Molecules (N₂)

### 2.1 The Problem with LJ Only

If we want to simulate nitrogen gas (N₂), LJ alone is insufficient:
- Two N atoms would just bounce off each other
- No permanent bond holding them together
- Molecules would dissociate at high temperature

**Solution:** Add a **bond potential**.

### 2.2 What Bonds Add

With bonds, we can now predict:
- ✅ Bond vibration frequency (IR spectroscopy)
- ✅ Heat capacity (vibrational contribution)
- ✅ Molecular identity (N₂ stays intact)

**Still Cannot Predict:**
- ❌ Molecular shape (linear vs. bent) — needs angles
- ❌ Internal rotation — needs dihedrals

### 2.3 LAMMPS Input File

Create `nitrogen_bonded.in`:

```lammps
# Nitrogen Gas (N2) - LJ + Harmonic Bonds
# Tutorial 11 - Part 2

units           real
atom_style      molecular               # Atoms with bonds
boundary        p p p

# ========================================
# Create Atoms Manually
# ========================================
read_data       n2_system.data          # Read pre-built structure

# ========================================
# Force Field
# ========================================
# Non-bonded: LJ (even for bonded atoms, applies to inter-molecular)
pair_style      lj/cut 10.0
pair_coeff      1 1 0.0690 3.31         # N atom LJ parameters

# Bonded: Harmonic bond
bond_style      harmonic
bond_coeff      1 200.0 1.10            # k=200 kcal/mol/A^2, r0=1.10 A (N≡N)

# CRITICAL: Exclude 1-2 interactions from LJ
special_bonds   lj 0.0 0.0 0.5          # Scale 1-2, 1-3, 1-4 by 0, 0, 0.5

# ========================================
# Settings
# ========================================
neighbor        2.0 bin
neigh_modify    delay 0 every 1 check yes

# ========================================
# Equilibration
# ========================================
velocity        all create 300.0 54321
fix             1 all nvt temp 300.0 300.0 100.0

timestep        1.0                     # 1 fs (smaller for bond vibrations)
thermo          1000
thermo_style    custom step temp pe ke etotal press

run             50000                   # 50 ps equilibration

# ========================================
# Production
# ========================================
reset_timestep  0

# Track bond length over time
compute         bonds all property/local btype batom1 batom2 blen
fix             2 all ave/time 1 1 100 c_bonds[*] file bond_lengths.dat mode vector

dump            1 all custom 1000 n2.lammpstrj id mol type x y z
run             100000                  # 100 ps production
```

### 2.4 Creating the Initial Structure

We need to create `n2_system.data`. 

**Step 1:** Navigate to the nitrogen directory and open Jupyter:

```bash
cd $SCRATCH/tutorial11/part2_nitrogen
```

**Step 2:** Create a new notebook `build_n2.ipynb`

**Notebook Cell 1: Build N₂ Structure**

```python
import numpy as np

# System parameters
n_molecules = 100
box_size = 30.0      # Angstroms
bond_length = 1.10   # N≡N equilibrium bond length

# Write LAMMPS data file
with open('n2_system.data', 'w') as f:
    f.write('N2 system - 100 molecules\n\n')
    f.write(f'{n_molecules*2} atoms\n')
    f.write(f'{n_molecules} bonds\n')
    f.write('0 angles\n')
    f.write('0 dihedrals\n\n')
    
    f.write('1 atom types\n')
    f.write('1 bond types\n\n')
    
    f.write(f'0.0 {box_size} xlo xhi\n')
    f.write(f'0.0 {box_size} ylo yhi\n')
    f.write(f'0.0 {box_size} zlo zhi\n\n')
    
    f.write('Masses\n\n')
    f.write('1 14.007  # Nitrogen\n\n')
    
    f.write('Atoms  # molecular\n\n')
    
    atom_id = 1
    for mol_id in range(1, n_molecules + 1):
        # Random position for molecule center
        center = np.random.rand(3) * box_size
        
        # Random orientation
        theta = np.random.rand() * np.pi
        phi = np.random.rand() * 2 * np.pi
        
        # Unit vector for bond direction
        direction = np.array([
            np.sin(theta) * np.cos(phi),
            np.sin(theta) * np.sin(phi),
            np.cos(theta)
        ])
        
        # Two nitrogen atoms
        pos1 = center - 0.5 * bond_length * direction
        pos2 = center + 0.5 * bond_length * direction
        
        f.write(f'{atom_id} {mol_id} 1 0.0 {pos1[0]:.6f} {pos1[1]:.6f} {pos1[2]:.6f}\n')
        atom_id += 1
        f.write(f'{atom_id} {mol_id} 1 0.0 {pos2[0]:.6f} {pos2[1]:.6f} {pos2[2]:.6f}\n')
        atom_id += 1
    
    f.write('\nBonds\n\n')
    
    bond_id = 1
    for mol_id in range(1, n_molecules + 1):
        atom1 = (mol_id - 1) * 2 + 1
        atom2 = atom1 + 1
        f.write(f'{bond_id} 1 {atom1} {atom2}\n')
        bond_id += 1

print(f"✓ Created n2_system.data with {n_molecules} N2 molecules")
print(f"✓ File saved in current directory: {!r}")

# Verify file was created
import os
if os.path.exists('n2_system.data'):
    size = os.path.getsize('n2_system.data')
    print(f"✓ File size: {size} bytes")
else:
    print("✗ ERROR: File not created!")
```

```python
import numpy as np

# Load bond lengths
data = np.loadtxt('bond_lengths.dat')

plt.axvline(x=1.10, color='r', linestyle='--', linewidth=2, label='r₀ = 1.10 Å')
plt.axvline(x=mean_length, color='g', linestyle='-', linewidth=2, 
            label=f'Mean = {mean_length:.4f} Å')
plt.xlabel('Bond Length (Å)', fontsize=12)
plt.ylabel('Probability Density', fontsize=12)
plt.title('Bond Length Distribution', fontsize=13, fontweight='bold')
plt.legend()
plt.grid(alpha=0.3)

plt.tight_layout()
plt.savefig('bond_analysis.png', dpi=150)
plt.show()

print(f"\nBond Statistics:")
print(f"  Mean length: {mean_length:.4f} Å")
print(f"  Std dev: {std_length:.4f} Å")
print(f"  Equilibrium: 1.10 Å")
print(f"\n→ Bonds vibrate around equilibrium")
print(f"→ Standard deviation related to temperature")
```

**Key Observation:**
The bond vibrates around 1.10 Å but never breaks. At 300 K, the thermal energy (~0.6 kcal/mol) is much smaller than the bond strength.

## Part 3: Water - Adding Angles

### 3.1 Why Angles Matter

Water (H₂O) is not linear—the H-O-H angle is 104.5°. This angle is crucial for:
- Molecular dipole moment
- Hydrogen bonding geometry
- Ice structure (why ice floats)

**With angles, we can predict:**
- ✅ Molecular geometry
- ✅ Accurate electrostatics (charge distribution)
- ✅ Phase behavior (liquid vs. ice)

### 3.2 LAMMPS Input: TIP3P Water

Create `water_tip3p.in`:

```lammps
# Water - TIP3P Model (LJ + Bonds + Angles + Charges)
# Tutorial 11 - Part 3

units           real
atom_style      full                    # Includes charges, bonds, angles
boundary        p p p

# ========================================
# Read Structure
# ========================================
read_data       water_box.data

# ========================================
# Force Field
# ========================================
# Non-bonded: LJ + Coulombic
pair_style      lj/cut/coul/long 10.0   # LJ cutoff 10 A, long-range Coulomb
pair_coeff      1 1 0.1521 3.1507       # O-O (TIP3P)
pair_coeff      2 2 0.0000 0.0000       # H-H (no LJ)
kspace_style    pppm 1.0e-4             # Particle-Particle Particle-Mesh (Ewald)

# Bonds: O-H
bond_style      harmonic
bond_coeff      1 450.0 0.9572          # k=450 kcal/mol/A^2, r0=0.9572 A

# Angles: H-O-H
angle_style     harmonic
angle_coeff     1 55.0 104.52           # k=55 kcal/mol/rad^2, theta0=104.52 deg

# Exclusions
special_bonds   lj/coul 0.0 0.0 0.5     # Exclude 1-2, 1-3; scale 1-4 by 0.5

# ========================================
# Settings
# ========================================
neighbor        2.0 bin
neigh_modify    delay 0 every 1 check yes

# ========================================
# Equilibration (NPT to get correct density)
# ========================================
velocity        all create 300.0 98765
fix             1 all npt temp 300.0 300.0 100.0 iso 1.0 1.0 1000.0

timestep        1.0                     # 1 fs
thermo          1000
thermo_style    custom step temp pe ke etotal press density vol

run             50000                   # 50 ps NPT equilibration

# ========================================
# Production (NVT)
# ========================================
unfix           1
fix             2 all nvt temp 300.0 300.0 100.0

reset_timestep  0
dump            1 all custom 1000 water.lammpstrj id mol type q x y z
dump_modify     1 sort id

# Compute RDF (O-O)
compute         rdf_oo all rdf 100 1 1
fix             3 all ave/time 100 10 1000 c_rdf_oo[*] file water_rdf_oo.dat mode vector

# Compute angle distribution
compute         angles all property/local atype aatom1 aatom2 aatom3 atheta
fix             4 all ave/time 1 1 100 c_angles[*] file angles.dat mode vector

run             100000                  # 100 ps production
```

### 3.3 Building the Water Box

**Navigate to the water directory:**
```bash
cd $SCRATCH/tutorial11/part3_water
```

**Create a new notebook: `build_water.ipynb`**

**Notebook Cell 1: Build TIP3P Water Box**

```python
import numpy as np

# Parameters
n_molecules = 216       # 6x6x6 grid
box_size = 18.6         # Angstroms (gives ~1 g/cm³ at equilibrium)
oh_bond = 0.9572        # TIP3P O-H bond length
hoh_angle = 104.52      # TIP3P H-O-H angle (degrees)

# Convert angle to radians
theta = np.radians(hoh_angle)

# Calculate H positions relative to O
# Place O at origin, one H along +x, other at angle
h1_rel = np.array([oh_bond, 0.0, 0.0])
h2_rel = np.array([oh_bond * np.cos(theta), oh_bond * np.sin(theta), 0.0])

print("Building water box...")
print(f"  Molecules: {n_molecules}")
print(f"  Box size: {box_size} Å")
print(f"  Target density: ~1.0 g/cm³")

# Write data file
with open('water_box.data', 'w') as f:
    f.write('TIP3P Water - 216 molecules\n\n')
    f.write(f'{n_molecules*3} atoms\n')
    f.write(f'{n_molecules*2} bonds\n')
    f.write(f'{n_molecules} angles\n')
    f.write('0 dihedrals\n\n')
    
    f.write('2 atom types  # 1=O, 2=H\n')
    f.write('1 bond types\n')
    f.write('1 angle types\n\n')
    
    f.write(f'0.0 {box_size} xlo xhi\n')
    f.write(f'0.0 {box_size} ylo yhi\n')
    f.write(f'0.0 {box_size} zlo zhi\n\n')
    
    f.write('Masses\n\n')
    f.write('1 15.9994  # O\n')
    f.write('2 1.008    # H\n\n')
    
    f.write('Atoms  # full\n\n')
    
    # Place molecules on a grid
    nx = int(round(n_molecules**(1/3)))
    spacing = box_size / nx
    
    atom_id = 1
    mol_id = 1
    
    for i in range(nx):
        for j in range(nx):
            for k in range(nx):
                # Random orientation for each molecule
                # Use Euler angles to rotate
                phi = np.random.rand() * 2 * np.pi
                theta_rot = np.random.rand() * np.pi
                psi = np.random.rand() * 2 * np.pi
                
                # Rotation matrix (simplified)
                cos_t, sin_t = np.cos(theta_rot), np.sin(theta_rot)
                cos_p, sin_p = np.cos(phi), np.sin(phi)
                
                rot = np.array([
                    [cos_p, -sin_p, 0],
                    [sin_p, cos_p, 0],
                    [0, 0, 1]
                ]) @ np.array([
                    [cos_t, 0, sin_t],
                    [0, 1, 0],
                    [-sin_t, 0, cos_t]
                ])
                
                # Molecule center
                center = np.array([
                    (i + 0.5) * spacing,
                    (j + 0.5) * spacing,
                    (k + 0.5) * spacing
                ])
                
                # Atom positions
                o_pos = center
                h1_pos = center + rot @ h1_rel
                h2_pos = center + rot @ h2_rel
                
                # Write atoms (id mol type q x y z)
                f.write(f'{atom_id} {mol_id} 1 -0.834 {o_pos[0]:.6f} {o_pos[1]:.6f} {o_pos[2]:.6f}\n')
                atom_id += 1
                f.write(f'{atom_id} {mol_id} 2 0.417 {h1_pos[0]:.6f} {h1_pos[1]:.6f} {h1_pos[2]:.6f}\n')
                atom_id += 1
                f.write(f'{atom_id} {mol_id} 2 0.417 {h2_pos[0]:.6f} {h2_pos[1]:.6f} {h2_pos[2]:.6f}\n')
                atom_id += 1
                
                mol_id += 1
    
    # Write bonds
    f.write('\nBonds\n\n')
    bond_id = 1
    for mol in range(1, n_molecules + 1):
        o_atom = (mol - 1) * 3 + 1
        h1_atom = o_atom + 1
        h2_atom = o_atom + 2
        
        f.write(f'{bond_id} 1 {o_atom} {h1_atom}\n')
        bond_id += 1
        f.write(f'{bond_id} 1 {o_atom} {h2_atom}\n')
        bond_id += 1
    
    # Write angles
    f.write('\nAngles\n\n')
    angle_id = 1
    for mol in range(1, n_molecules + 1):
        o_atom = (mol - 1) * 3 + 1
        h1_atom = o_atom + 1
        h2_atom = o_atom + 2
        
        f.write(f'{angle_id} 1 {h1_atom} {o_atom} {h2_atom}\n')
        angle_id += 1

print(f"\n✓ Created water_box.data with {n_molecules} water molecules")
print(f"✓ Total atoms: {n_molecules * 3}")
print(f"✓ Total bonds: {n_molecules * 2}")
print(f"✓ Total angles: {n_molecules}")

# Verify file
import os
if os.path.exists('water_box.data'):
    size = os.path.getsize('water_box.data') / 1024  # KB
    print(f"✓ File size: {size:.1f} KB")
    print("\n Ready to run LAMMPS simulation!")
else:
    print("✗ ERROR: File not created!")
```

## Part 4: Ethane - Adding Dihedrals

### 4.1 Why Dihedrals Matter

Ethane (H₃C-CH₃) can rotate around the C-C bond. The "staggered" conformation (H atoms far apart) is more stable than "eclipsed" (H atoms aligned).

**With dihedrals, we can predict:**
- ✅ Conformational preferences
- ✅ Rotational barriers
- ✅ Free energy landscapes
- ✅ Polymer chain statistics

```python
import numpy as np

# Single ethane molecule in a box
box_size = 15.0

# Atom positions (hand-built staggered conformation)
# Carbon 1 at origin, Carbon 2 along x-axis
c1 = np.array([0.0, 0.0, 0.0])
c2 = np.array([1.529, 0.0, 0.0])

# Hydrogens on C1 (tetrahedral, 109.5 deg)
theta_tet = np.radians(109.47)
h1_c1 = c1 + 1.09 * np.array([-np.cos(theta_tet), np.sin(theta_tet), 0.0])
h2_c1 = c1 + 1.09 * np.array([-np.cos(theta_tet), -np.sin(theta_tet)/2, np.sqrt(3)/2*np.sin(theta_tet)])
h3_c1 = c1 + 1.09 * np.array([-np.cos(theta_tet), -np.sin(theta_tet)/2, -np.sqrt(3)/2*np.sin(theta_tet)])

# Hydrogens on C2 (staggered)
h1_c2 = c2 + 1.09 * np.array([np.cos(theta_tet), np.sin(theta_tet), 0.0])
h2_c2 = c2 + 1.09 * np.array([np.cos(theta_tet), -np.sin(theta_tet)/2, np.sqrt(3)/2*np.sin(theta_tet)])
h3_c2 = c2 + 1.09 * np.array([np.cos(theta_tet), -np.sin(theta_tet)/2, -np.sqrt(3)/2*np.sin(theta_tet)])

# Center molecule in box
center = np.array([box_size/2, box_size/2, box_size/2])
atoms = [c1, c2, h1_c1, h2_c1, h3_c1, h1_c2, h2_c2, h3_c2]
atoms = [a + center for a in atoms]

print("Building ethane molecule...")
print(f"  Box size: {box_size} Å")
print(f"  Atoms: 2 C + 6 H = 8 total")

with open('ethane.data', 'w') as f:
    f.write('Ethane molecule\n\n')
    f.write('8 atoms\n')
    f.write('7 bonds\n')
    f.write('12 angles\n')
    f.write('9 dihedrals\n\n')
    
    f.write('2 atom types  # 1=C, 2=H\n')
    f.write('2 bond types  # 1=C-C, 2=C-H\n')
    f.write('2 angle types # 1=C-C-H, 2=H-C-H\n')
    f.write('1 dihedral types\n\n')
    
    f.write(f'0.0 {box_size} xlo xhi\n')
    f.write(f'0.0 {box_size} ylo yhi\n')
    f.write(f'0.0 {box_size} zlo zhi\n\n')
    
    f.write('Masses\n\n')
    f.write('1 12.011  # C\n')
    f.write('2 1.008   # H\n\n')
    
    f.write('Atoms  # full\n\n')
    # C1, C2, then Hs
    types = [1, 1, 2, 2, 2, 2, 2, 2]
    charges = [-0.18, -0.18, 0.06, 0.06, 0.06, 0.06, 0.06, 0.06]
    
    for i, (pos, atype, q) in enumerate(zip(atoms, types, charges), 1):
        f.write(f'{i} 1 {atype} {q} {pos[0]:.6f} {pos[1]:.6f} {pos[2]:.6f}\n')
    
    # Bonds
    f.write('\nBonds\n\n')
    bonds = [
        (1, 1, 2),      # C-C
        (2, 1, 3),      # C-H
        (2, 1, 4),
        (2, 1, 5),
        (2, 2, 6),
        (2, 2, 7),
        (2, 2, 8),
    ]
    for bid, (btype, a1, a2) in enumerate(bonds, 1):
        f.write(f'{bid} {btype} {a1} {a2}\n')
    
    # Angles (C-C-H and H-C-H)
    f.write('\nAngles\n\n')
    angles = [
        (1, 3, 1, 2), (1, 4, 1, 2), (1, 5, 1, 2),  # H-C1-C2
        (1, 6, 2, 1), (1, 7, 2, 1), (1, 8, 2, 1),  # H-C2-C1
        (2, 3, 1, 4), (2, 3, 1, 5), (2, 4, 1, 5),  # H-C1-H
        (2, 6, 2, 7), (2, 6, 2, 8), (2, 7, 2, 8),  # H-C2-H
    ]
    for aid, (atype, a1, a2, a3) in enumerate(angles, 1):
        f.write(f'{aid} {atype} {a1} {a2} {a3}\n')
    
    # Dihedrals (H-C-C-H)
    f.write('\nDihedrals\n\n')
    dihedrals = [
        (1, 3, 1, 2, 6),
        (1, 3, 1, 2, 7),
        (1, 3, 1, 2, 8),
        (1, 4, 1, 2, 6),
        (1, 4, 1, 2, 7),
        (1, 4, 1, 2, 8),
        (1, 5, 1, 2, 6),
```

## Summary and Key Lessons

### What We Learned

| Potential | System | New Physics | Predicted Properties |
|-----------|--------|-------------|---------------------|
| **LJ only** | Argon liquid | van der Waals forces | Structure (RDF), density, diffusion |
| **+ Bonds** | N₂ gas | Permanent bonds | Molecular identity, vibrations |
| **+ Angles** | Water (TIP3P) | Molecular geometry | H-bonding, ice structure |
| **+ Dihedrals** | Ethane | Internal rotation | Conformational equilibria |

### Critical Observations

1. **LJ cannot predict molecular properties** — Everything "dissolves" into atoms

2. **Bonds create molecules** — But molecules are still floppy without angles

3. **Angles create shapes** — Water's 104.5° angle is why ice floats

4. **Dihedrals create conformational complexity** — Essential for proteins, polymers

### Computational Cost Scaling

From the log files, compare:
- **Argon (LJ):** ~X timesteps/second
- **N₂ (bonds):** ~0.8X timesteps/second (slightly slower)
- **Water (angles + Coulomb):** ~0.3X timesteps/second (PME dominates)
- **Ethane (full FF):** ~0.6X timesteps/second

**Lesson:** Electrostatics (long-range Coulomb) is the main bottleneck, not bonded terms.
